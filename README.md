Selected Work
1. Decentralized Hybrid LLM Inference on Free-Tier GPUs

Type: Research + Systems Experimentation

A systems-focused research project exploring whether modern LLMs can realistically run on free-tier GPU infrastructure, and what breaks when you try.
Empirical testing on Kaggle GPUs (T4/P100).
Deployment using open-weight models.
Measured TTFT, throughput, VRAM usage, and failure modes.
Public GitHub artifacts and execution logs for reproducibility.

→ GitHub: https://github.com/thedevx-shivansh/free-tier-llm-inference-dhlia

→ Kaggle execution log: https://www.kaggle.com/code/shivanshdevx/free-tier-llm-inference-validation

This project is part of an ongoing research paper submission.

2. NeuroCommander (Gemini Hackathon Project)

Type: Hackathon / Applied AI System

An experimental multi-stage AI system built for the Kaggle × Google DeepMind Gemini hackathon.
The goal was to explore structured reasoning pipelines rather than simple chat responses.
Multi-stage reasoning and arbitration.
Structured JSON outputs for frontend rendering.
Full-stack prototype (backend + UI).
Built as an experiment, not a production system.

→ GitHub: https://github.com/thedevx-shivansh/NeuroCommander-DECISIO
→ Live demo: https://neurocommander-decisio.onrender.com
