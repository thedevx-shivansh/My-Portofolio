## Selected Work

### 1. Decentralized Hybrid LLM Inference on Free-Tier GPUs  
**Type:** Research + Systems Experimentation  

A systems-focused research project exploring whether modern large language models can **realistically run on free-tier GPU infrastructure**, and what breaks when you try.

This project is centered on **empirical validation**, not benchmarks or training.

**What was done:**
- Executed inference on Kaggle free-tier GPUs (T4 / P100)
- Deployed open-weight, quantized LLMs
- Measured:
  - time-to-first-token (TTFT)
  - token throughput
  - VRAM usage
  - stability and failure modes
- Published raw execution artifacts for reproducibility

**Links:**
- GitHub repository:  
  https://github.com/thedevx-shivansh/free-tier-llm-inference-dhlia  
- Kaggle execution log:  
  https://www.kaggle.com/code/shivanshdevx/free-tier-llm-inference-validation
- Zenodo Record:

This project is part of an **ongoing student research paper submission**.

### 2. NeuroCommander  
**Type:** Hackathon / Applied AI System  

An experimental multi-stage AI system built for the **Kaggle × Google DeepMind Gemini Hackathon**.

The goal was to explore **structured reasoning pipelines**, not to build a production chatbot.

**What was explored:**
- Multi-stage reasoning and arbitration
- Role-based system prompting
- Structured JSON outputs for frontend rendering
- Full-stack prototype (backend + UI)

This project was built as an **experiment under hackathon constraints**, not as a maintained service.
